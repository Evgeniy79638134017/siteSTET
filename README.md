# siteSTET

Сайт магазина бьюти-оборудования **«Стиль Салон»** — г. Благовещенск.

## Структура
Проект находится в подпапке `beauty-site/`.

## Стек
Astro 5 + Tailwind CSS 4 + MDX + TypeScript

## Запуск
```bash
cd beauty-site
npm install
npm run dev
```

## Деплой
Vercel → Root Directory: `beauty-site`
